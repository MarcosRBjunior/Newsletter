# Masthead

Cabeçalho da publicação: kicker mono, nome em Fraunces 900 e navegação mono com o botão Subscribe.

- Fecha com régua `stroke-heavy` em `rule`.
- Nome em estilo `masthead`, sempre "THE LONG VIEW" em caixa-alta.
- Links no estilo `nav`; hover `hot`. Abaixo de 768px o nav some (`hidden md:flex`).
- O consumidor fornece os links âncora (`#issues`, `#archive`, `#about`, `#subscribe`).
