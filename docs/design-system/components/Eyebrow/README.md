# Eyebrow

Rótulo mono em caixa-alta que anuncia um título: estilo `eyebrow` (10px, tracking .25em).

- Em `hot` acima de títulos de seção ("Archive", "About", "Latest Issue · No. 031").
- Em `ink-40` (`--muted`) para contagens ("6 issues"). Atenção: `ink-40` sobre `paper` = 2.69:1.
- Separe itens com ` · `. Nunca mais de uma linha.
