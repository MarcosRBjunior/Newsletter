# ArchiveRow

Linha do arquivo: número mono, título Fraunces 600, data + badge e seta.

- Lista dentro de `lv-archive` (borda esquerda `stroke-mid`, recuo `space-8`); linhas separadas por `ink-15`, a última sem borda.
- Hover: número, título e seta em `hot`.
- O consumidor fornece `{id, date, title, category}`.
